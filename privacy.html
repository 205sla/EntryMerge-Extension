개인정보 처리방침 (Privacy Policy)

시행일자: 2025년 1월 18일

EntryMerge - 엔트리 작품 합치기 (이하 "본 확장 프로그램")는 사용자의 개인정보 보호를 최우선으로 생각하며, 구글 크롬 웹 스토어의 개발자 프로그램 정책 및 관련 개인정보 보호 법령을 철저히 준수합니다. 본 개인정보 처리방침은 본 확장 프로그램이 사용자의 데이터를 어떻게 취급하는지 안내하기 위해 작성되었습니다.

1. 개인정보의 수집 및 이용

본 확장 프로그램은 어떠한 형태의 개인정보(이름, 이메일, IP 주소, 브라우징 기록 등)도 수집, 저장, 또는 외부 서버로 전송하지 않습니다. 본 확장 프로그램은 오직 사용자의 브라우저 내부(로컬 환경)에서만 동작하며, 서버나 데이터베이스를 별도로 운영하지 않는 순수 클라이언트 사이드(Client-side) 도구입니다.

2. 사용자 데이터 접근 권한 및 목적

본 확장 프로그램은 엔트리(Entry) 작품 파일(.ent)을 합치는 기능을 제공하며, 추가적인 브라우저 권한을 요청하지 않습니다.

  • 파일 접근: 사용자가 직접 드래그 앤 드롭 또는 파일 선택 대화상자를 통해 선택한 .ent 파일에 한하여 표준 File API를 통해 읽기를 수행합니다. 사용자의 명시적 행위 없이는 어떠한 파일에도 접근하지 않습니다.
  • 데이터 처리: 선택된 파일의 압축 해제, 병합, 재압축 과정이 모두 브라우저 메모리 내에서 수행됩니다. 처리 완료 후 결과 파일은 사용자의 다운로드 폴더에 저장되며, 메모리에 남은 데이터는 즉시 해제됩니다.
  • 위 과정을 통해 처리된 데이터는 외부로 전송되거나 서버에 백업되지 않으며, 전적으로 사용자의 브라우저 내부에서만 처리됩니다.

3. 개인정보의 제3자 제공 및 공유

본 확장 프로그램은 수집하는 개인정보가 없으므로, 제3자에게 데이터를 제공하거나 공유하는 일 또한 절대 발생하지 않습니다. 본 확장 프로그램은 외부 분석 도구, 광고 네트워크, 또는 기타 제3자 서비스와 일체 연동되지 않습니다.

4. 쿠키 및 브라우저 저장소

본 확장 프로그램은 쿠키, localStorage, sessionStorage, IndexedDB 또는 기타 브라우저 저장소를 사용하지 않습니다. 사용자의 설정이나 작업 내역을 별도로 기록하지 않으며, 확장 프로그램을 닫으면 모든 임시 데이터는 소멸됩니다.

5. 개인정보의 파기

수집 및 저장하는 개인정보가 없으므로 파기할 개인정보 데이터가 존재하지 않습니다. 브라우저에서 확장 프로그램을 삭제(Remove)하면 관련된 모든 데이터가 즉시 제거됩니다.

6. 아동의 개인정보 보호

본 확장 프로그램은 모든 연령대의 사용자가 안전하게 사용할 수 있습니다. 우리는 만 13세 미만 아동의 개인정보를 포함하여 그 누구의 데이터도 고의로 수집하지 않습니다.

7. 개인정보 처리방침의 변경

본 개인정보 처리방침은 법령 또는 확장 프로그램 기능의 변경에 따라 수정될 수 있습니다. 변경 사항이 있을 경우, 본 페이지를 통해 공지합니다.
